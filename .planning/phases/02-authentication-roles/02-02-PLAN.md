  - Add a `get_current_user` async dependency function that:
    1. Takes `authorization: str = Header(None)` or use `OAuth2PasswordBearer(tokenUrl="token", auto_error=False)` to extract the Bearer token
    2. If no token, raise `HTTPException(401, "Not authenticated")`

       ```python
       from app.db.session import get_supabase

       user_response = sb.auth.get_user(token)
       ```
       This is the simplest and most reliable approach -- Supabase validates its own tokens.
    4. If validation fails (exception or no user), raise `HTTPException(401, "Invalid or expired token")`

The Supabase Python SDK handles validation internally, and this avoids issues with JWKS rotation, algorithm mismatches, and audience claims. The `get_supabase()` uses the service role key which has permission to validate any user's token.

  **Rewrite the auth interceptor in `frontend/src/lib/api.ts`:**
  - The current interceptor reads from `localStorage.getItem("authToken")` which is NEVER set by our code (Supabase manages its own storage)
  - Replace the interceptor to get the token from Supabase's session:
    ```typescript
    import { supabase } from '@/lib/supabase';

    api.interceptors.request.use(
      async (config) => {
        const { data: { session } } = await supabase.auth.getSession();
        if (session?.access_token) {
          config.headers.Authorization = `Bearer ${session.access_token}`;
        }
        return config;
      },
      (error) => Promise.reject(error)
    );
    ```
  - Note: This uses the standalone supabase client from `@/lib/supabase.ts` because the Axios module is NOT a React component and cannot use hooks. This is the correct pattern -- the standalone client shares the same storage as the provider client (both read from the same localStorage).
  - Add a response interceptor that handles 401 responses by redirecting to /auth/login:
    ```typescript
    api.interceptors.response.use(
      (response) => response,
      (error) => {
        if (error.response?.status === 401) {
          // Token expired or invalid -- redirect to login
          if (typeof window !== 'undefined') {
            window.location.href = '/auth/login';
          }
        }
        return Promise.reject(error);
      }
    );
    ```
  - Keep all the API endpoint definitions (authAPI, athleteAPI, trainingAPI, performanceAPI) as-is
  - Update `authAPI` to remove the old login/googleLogin methods (those now go through Supabase directly, not the backend):
    ```typescript
    export const authAPI = {
      me: () => api.get('/api/auth/me'),
    };
    ```
