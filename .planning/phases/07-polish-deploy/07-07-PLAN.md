  <action>
    1. Add `apscheduler==3.10.4` to `backend/requirements.txt`.

    2. Create `backend/app/scheduler.py`:
       - Import `AsyncIOScheduler` from `apscheduler.schedulers.asyncio`
       - Import `CronTrigger` from `apscheduler.triggers.cron`
       - Create scheduler instance: `scheduler = AsyncIOScheduler()`
       - Create `async def generate_weekly_plans_job()`:
         - Import CoachRepository and PlanGenerationService inside the function (lazy import to avoid circular imports)
         - Calculate next Monday date: `today + timedelta(days=(7 - today.weekday()) % 7 or 7)`
         - Get all active coaches via `CoachRepository().get_all_active()`
         - For each coach, call the plan generation service's batch generation method
         - Wrap each coach's generation in try/except so one coach's failure doesn't block others
         - Log success/failure using Python logging module
       - Register the job with CronTrigger:
         - `day_of_week='sat'`, `hour=22`, `minute=0`
         - `id='weekly_plan_generation'`, `replace_existing=True`
       - Also create `async def check_unreviewed_plans_job()`:
         - Runs Monday at 8 AM
         - Queries for plans still in pending_review status for the current week
         - Logs a warning for each coach with unreviewed plans (in-app alert is already computed on read from Phase 5/6 alerts system)
         - This is informational logging, not a notification (push notifications deferred)
       - Register the check job: `day_of_week='mon'`, `hour=8`

    3. Update `backend/app/main.py`:
       - Read existing file first
       - Add FastAPI lifespan event handler using `@asynccontextmanager`:
         ```python
         from contextlib import asynccontextmanager

         @asynccontextmanager
         async def lifespan(app: FastAPI):
             from app.scheduler import scheduler
             scheduler.start()
             yield
             scheduler.shutdown()
         ```
       - Pass `lifespan=lifespan` to the `FastAPI()` constructor
       - This replaces the deprecated `@app.on_event("startup")` pattern

    4. Add environment variable to disable scheduler in tests:
       - In config.py, add `ENABLE_SCHEDULER: bool = True`
       - In scheduler.py startup, check `settings.ENABLE_SCHEDULER` before starting
       - In docker-compose, ENABLE_SCHEDULER defaults to True
  </action>
