         - **Typography**: Clean, readable sans-serif. Mantine uses system font stack by default which is excellent. Define heading scales for mobile (compact) and desktop (spacious).

         - Typography rationale (readability at gym distances)

         - Component patterns (cards, forms, data tables, charts)
         - Do's and Don'ts
