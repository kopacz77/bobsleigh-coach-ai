<objective>
Build the mobile-optimized active workout experience for athletes at the gym. One-tap start from dashboard, exercise-by-exercise set logging, rest timer between sets, and screen wake lock.

Purpose: The core athlete experience happens at the gym with a phone. They need large touch targets, minimal typing, a rest timer they can glance at, and a screen that stays awake. This is the UX that makes the app worth using over a paper notebook.

Output: Active workout flow (dashboard -> workout page -> set logging -> rest timer). Custom hooks for wake lock and rest timer. Mobile-optimized UI with large buttons and easy data entry.
</objective>

    1. Create `frontend/src/hooks/useWakeLock.ts`:
       - Check `navigator.wakeLock` support (SSR-safe: check `typeof navigator !== 'undefined'`)
       - `request()` function to acquire wake lock
       - `release()` function to release wake lock
       - Auto-reacquire on `visibilitychange` event when document becomes visible again (critical: browser releases wake lock when tab is hidden, must re-acquire when athlete comes back to the app)
       - Return `{ isActive, isSupported, request, release }`
       - Clean up event listener on unmount
       - Follow the exact pattern from 07-RESEARCH.md

    2. Create `frontend/src/hooks/useRestTimer.ts`:
       - Takes `defaultSeconds` parameter (default: 120 for 2-minute rest)
       - `start(seconds?)` function to begin countdown from given seconds
       - `stop()` function to cancel countdown
       - `reset()` function to reset to default
       - Uses `setInterval` with 1-second ticks
       - When timer reaches 0:
         - Play audio notification: `new Audio('/sounds/timer-end.mp3').play().catch(() => {})` (catch for autoplay policy)
         - Vibrate if supported: `if ('vibrate' in navigator) navigator.vibrate([200, 100, 200])` (Android Chrome only, not Safari/Firefox)
         - Audio is PRIMARY notification, vibrate is ENHANCEMENT
       - Return `{ remaining, isRunning, start, stop, reset }`
       - Clean up interval on unmount

    3. Create a simple audio file placeholder:
       - Create `frontend/public/sounds/` directory
       - The actual mp3 can be added later -- the code should gracefully handle missing audio
  </action>
