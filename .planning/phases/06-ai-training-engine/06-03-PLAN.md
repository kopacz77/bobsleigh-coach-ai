  <name>Task 1: Build morning adaptation service</name>
  <files>backend/app/services/morning_adaptation_service.py</files>
  <action>
Create MorningAdaptationService that takes today's planned workout data and an athlete's morning wellness check-in, and returns adapted loads.

Implement `adapt_workout(plan_day: dict, athlete_user_id: str) -> dict` that:

1. Fetches today's wellbeing check-in for the athlete from wellbeing_assessments table (query by user_id + date = today). If no check-in exists, return plan_day unmodified with adaptation_applied = False.

2. Calculates readiness score using the same formula as wellbeing.py and coach_service.py:
   ```python
   readiness = (sleep_quality + (10 - stress_level) + nutrition_quality + physical_readiness + mental_clarity) / 5
   ```

3. Determines multiplier based on readiness (from 06-RESEARCH.md):
   - 8-10: multiplier = 1.0 (no change)
   - 6-7.9: multiplier = 0.90 (mild reduction)
   - 4-5.9: multiplier = 0.80 (moderate reduction)
   - 2-3.9: multiplier = 0.65 (significant reduction)
   - < 2: multiplier = 0.50 (severe, flag for coach)

4. Applies multiplier to all exercises in the day that have planned_weight_kg:
   - adapted_weight_kg = round_to_plate(planned_weight_kg * multiplier)
   - round_to_plate: round to nearest 2.5kg

5. For readiness < 4: also reduce reps (adapted_reps = max(1, int(planned_reps * 0.75)))

6. Returns the adapted day dict with additional metadata:
   ```python
   {
       **plan_day,  # original plan data preserved
       "adaptation": {
           "applied": True,
           "readiness_score": readiness,
           "multiplier": multiplier,
           "message": "Slightly lighter today - listen to your body",  # varies by tier
           "coach_alert": readiness < 2  # True if severe
       },
       "sections": [adapted_sections]  # sections with adapted_weight_kg and adapted_reps added
   }
   ```

7. IMPORTANT: Do NOT modify the original plan_data. The adapted values are ADDITIONAL fields alongside the planned values (planned_weight_kg stays, adapted_weight_kg is added).

Messages by readiness tier:
- 8-10: "You're ready - go as planned"
- 6-7.9: "Slightly lighter today - listen to your body"
- 4-5.9: "Reduced load today - focus on quality"
- 2-3.9: "Light session recommended - recovery priority"
- < 2: "Recovery day strongly recommended"

Follow existing service patterns: class-based, async, get_supabase().
