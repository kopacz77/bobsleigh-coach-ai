Create 3 athlete-facing components using Mantine UI v7.

**AdaptedWorkoutView.tsx** - Today's workout with adaptation
- Uses useTodaysWorkout() hook from usePlans.ts
- Loading state: Loader spinner
- No plan state: Card with message "No approved plan for this week. Check back after your coach reviews."
- Rest day state: Card with message "Rest day - recovery is training too" + rest day tips
- Active day:
  - Show session title, session_type badge, estimated_duration
  - If adaptation.applied: show Alert with adaptation.message (color based on multiplier: green for 1.0, yellow for 0.9, orange for 0.8, red for < 0.8)
  - For each section (warm_up, main, accessory, cool_down):
    - Section header (e.g., "Warm-Up", "Main Work", "Accessory", "Cool-Down")
    - For each exercise: show name, sets x reps, weight
    - If adaptation applied and exercise has both planned_weight_kg and adapted_weight_kg:
      - Show adapted_weight_kg as the primary value (bold)
      - Show planned_weight_kg as strikethrough in lighter text: "~~180kg~~ 162.5kg"
      - Same for adapted_reps if present
    - If exercise has no weight (e.g., sprints), show distance/duration instead
    - Show rest_seconds as "Rest: 2min" format
    - Show notes if present
  - Target RPE at the top of the workout

**InjuryRiskBanner.tsx** - Injury risk warning
- Props: riskScore (number 0-1), riskLevel (string), riskFactors (string[])
- Only renders if riskLevel is "moderate" or "high"
- Mantine Alert component:
  - moderate: color="yellow", title="Elevated Injury Risk"
  - high: color="red", title="High Injury Risk Warning"
- Lists risk factors as bullet points
- Message: "Your training load patterns show elevated risk. Your coach has been notified."

**WeeklyPlanOverview.tsx** - Full week at a glance
- Uses useCurrentPlan() hook
- Loading/empty states
- Shows all 7 days in a vertical stack (mobile-friendly)
- Each day: Card with day_name, date, session_type badge (or "Rest" badge), title
- Today's day highlighted (different border color or background)
- Rest days shown with muted styling
- Training phase shown as a badge at the top
- InjuryRiskBanner at the top if risk is moderate/high

Use Mantine v7 props throughout: Card, Badge, Alert, Stack, Group, Text, Title, Paper, Divider.
