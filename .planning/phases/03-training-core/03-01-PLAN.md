  <action>
Create `backend/app/api/endpoints/exercises.py` with an APIRouter and two endpoints:

1. `GET /exercises` — List/search exercises with optional query params:
   - `search: Optional[str]` — case-insensitive name search using `.ilike(f"%{search}%")`
   - `category: Optional[str]` — exact match on category column
   - `muscle_group: Optional[str]` — filter where muscle_groups array contains the value (use `.contains([muscle_group])` on the jsonb/array column)
   - `limit: int = 50` — pagination limit
   - `offset: int = 0` — pagination offset
   - Returns list of exercise dicts from Supabase. No response_model (following established pattern from Phase 1).
   - Auth: `user=Depends(get_current_user)` — exercises are readable by any authenticated user.
   - Query: `get_supabase().table("exercises").select("*").eq("is_active", True)` with chained filters.
   - IMPORTANT: For text search, Supabase Python client uses `.ilike("name", f"*{search}*")` (asterisks, not percent signs).

2. `GET /exercises/categories` — Return distinct categories and muscle groups for filter dropdowns:
   - Query all active exercises, extract unique categories and muscle_groups values.
   - Return `{"categories": [...], "muscle_groups": [...]}`.

Follow the error handling pattern from training.py: try/except with HTTPException re-raise, RuntimeError->503, generic Exception->500.

Register the router in `backend/app/api/router.py`:
```python
from app.api.endpoints import exercises
api_router.include_router(exercises.router, prefix="/exercises", tags=["exercises"])
```

Add exercise API functions to `frontend/src/lib/api.ts`:
```typescript
export const exerciseAPI = {
  search: (params: { search?: string; category?: string; muscle_group?: string; limit?: number; offset?: number }) => {
    const queryString = new URLSearchParams(
      Object.entries(params).filter(([_, v]) => v !== undefined).map(([k, v]) => [k, String(v)])
    ).toString();
    return api.get(`/api/exercises?${queryString}`);
  },
  getCategories: () => api.get('/api/exercises/categories'),
};
```
