# Models Directory

This directory contains model definitions and trained model files.

## Structure

- `definitions/`: Python model architecture definitions
- `checkpoints/`: Trained model weights and checkpoints
- `configs/`: Model configuration files

## Model Types

1. **Performance Management Chart (PMC)** - Tracks fitness, fatigue, and form
2. **Training Load Predictor** - Predicts optimal training load for an athlete
3. **Injury Risk Model** - Predicts injury risk based on training patterns
4. **Performance Predictor** - Predicts competition performance based on training
