# Jupyter Notebooks

This directory contains Jupyter notebooks for exploring data, developing models, and visualizing results.

## Notebooks

- `01_data_exploration.ipynb`: Initial data exploration and visualization
- `02_feature_engineering.ipynb`: Development of features for models
- `03_pmc_model_development.ipynb`: Implementation of the Performance Management Chart model
- `04_training_load_prediction.ipynb`: Development of optimal training load prediction models
- `05_performance_prediction.ipynb`: Models for predicting competition performance

## Usage

1. Install dependencies from `ml/requirements.txt`
2. Start JupyterLab: `jupyter lab`
3. Open notebooks in order of numbering
